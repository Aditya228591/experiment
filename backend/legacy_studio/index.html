  • 📈 train_hf.py — Hugging Face fine-tuning script for scaling up

How to Run Anywhere 
# 1. Enter the exported folder
cd exported_slm/your_model_name

# 2. Run CLI prediction (runs in milliseconds!)
python serve.py --prompt "Your test input"

# 3. Or launch edge REST API server on port 8000
python serve.py --server

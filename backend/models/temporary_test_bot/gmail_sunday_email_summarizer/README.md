# Gmail Sunday Email Summarizer

Generated by **Teacher AI** — Standalone Automated Bot.

## Overview
- **Trigger Type:** `schedule`
- **Schedule:** `Every Sunday at 18:00`
- **Delivery Channel:** `ntfy_push`

### Execution Steps
1. Connect to Gmail via IMAP using read-only credentials every Sunday at 6:00 PM.
2. Fetch unread or recent emails received during the week.
3. Categorize and prioritize emails with events and updates as highest priority and spam as lowest priority.
4. Generate a concise priority-wise summary of the emails.
5. Send the final summary as a push notification to the specified ntfy.sh topic.

## Quickstart Setup

### 1. Install Dependencies
Ensure you have Python 3.9+ installed, then install the dependencies:
```bash
pip install -r requirements.txt
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Open `.env` and fill in your real credentials:
```env
GMAIL_USER=...
GMAIL_APP_PASSWORD=...
NTFY_TOPIC=...
```

## Running the Bot

### Simulated Dry-Run (Safe Test Mode)
Verify the bot without making real network calls or sending real notifications:
```bash
python bot.py --dry-run
```

### Single Execution Test
Execute the automation once immediately:
```bash
python bot.py --run-once
```

### Continuous Background Scheduler
Run the bot according to its configured schedule (`Every Sunday at 18:00`):
```bash
python bot.py
```
*(Press `Ctrl+C` to stop the scheduler).*
